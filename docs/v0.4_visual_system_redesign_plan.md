# Field Learning Studio — v0.4 Visual System Redesign Plan

This plan outlines the visual redesign sprint aimed at elevating Field Learning Studio from a functional prototype (v0.3) into a premium, calm, institutional evidence-to-learning workbench (v0.4). Target visual quality score: **8.2+/10** (up from ~6.3).

---

## 1. Current Visual Diagnosis
*   **Visual Width & Spacing Noise:** The workspace layout expands too flatly on large screens, creating cognitive fatigue.
*   **Color Overuse (Teal/Accent Fatigue):** Teal is overused on badges, pills, selection indicator states, and borders, muddying the visual hierarchy.
*   **Typography Scale:** Font sizes and weights lack editorial contrast. Eyebrow labels, metadata, and buttons feel default.
*   **Nested Boxes ("Box-in-Box" Syndrome):** Excessive bordered card wrappers inside sections create visual clutter.
*   **Layout Instability & Overflow Risks:** Side-by-side lessons/good practices have clipping risks on smaller viewports. The recommendations column priority layout is uneven.
*   **Traceability Drawer:** The signature feature (TraceChain and lineage drawer) lacks visual gravity.

---

## 2. Target Visual Direction
An institutional, serious, document-aware, and precise review environment:
*   **Clean Notion-like simplicity** paired with **Linear-like spacing discipline**.
*   **Colors:** Deep institutional teal as a focused primary accent; slate/charcoal for text; warm gray/off-white for paper canvasses.
*   **Calmer trace nodes:** Muted cyan-teal hover indicators and thin monospaced badges rather than thick saturated pills.
*   **Editorial typography:** High-contrast headings and relaxed line heights for qualitative review.

---

## 3. Design System Decisions

### A. Spacing & Container Shell
*   **Global Shell Wrapper:** Constrained to `max-w-6xl` (1152px) or `max-w-7xl` (1280px) for layout stability.
*   **Document Canvas (Brief Tab):** Constrained to `max-w-3xl` (768px) to feel like a real printable sheet.
*   **Traceability Drawer:** Sized to `w-full max-w-lg` (512px) for side-by-side review context.

### B. Typography & Microcopy
*   **Font Stack:** Clean sans-serif system font stack.
*   **Reduced Uppercase:** Lowercase text for tags/meta; uppercase reserved exclusively for status labels and safety warning tags.
*   **No Direct Quote Styling on Paraphrased Items:** Avoid quotes on paraphrased observations to preserve sanitization clarity.

### C. Color Roles & Palette
*   **Primary Accent:** `#0d9488` (Teal 600) / `#0f766e` (Teal 700) for interactive focus and traceability links.
*   **Neutral Text:** Slate (`text-slate-800` / `text-slate-500`).
*   **Borders:** Subtle gray (`border-slate-100` / `border-slate-200`).
*   **Safety Amber:** Warm amber (`bg-amber-50` / `text-amber-900` / `border-amber-200`) for the sandbox safety disclaimers.

---

## 4. Screen-by-Screen Redesign Plan

### 1. Hero / Top Screen
*   **Change:** Reorganize the top section into a professional split banner. The left side holds clean editorial copy. The right side features a visual pipeline transformation flow mapping raw notes to brief.
*   **Goal:** Provide first-screen clarity about the evidence-to-learning value within 10 seconds.

### 2. Case Selector Switcher
*   **Change:** Redesign the switcher into a clean card panel with subtle borders, dynamic evidence counts, safety statuses, and a explicit sanitization note.
*   **Safety Note:** Show clear disclaimer for the School Nutrition case: *"Sanitized demo derived from prior fieldwork. No identifiable school, child, staff, or community data is displayed."*

### 3. Overview Tab
*   **Change:** Reorder contents. Clear distinction between Guided Demo suggested path and the Sandbox Note simulator. Ensure the sandbox safety disclaimer is calm but prominent.

### 4. Evidence Tab
*   **Change:** Redesign the Evidence Cards. Remove quotation marks around observations. Reorganize hierarchy: Card title + ID, thematic tags, observation description, interpreted learning meaning, and the inspect chain button.

### 5. Findings Tab
*   **Change:** Emphasize the limitation modules. Style contradictory evidence summaries as a clean, amber-tinted caution note.

### 6. Lessons & Good Practices Tab
*   **P0 Change:** Fix clipping and horizontal alignment issues. Reorganize into a stacked single-column flow or a stable 2-column grid. Ensure the layouts are fully responsive without clipping text.

### 7. Recommendations Tab
*   **P0 Change:** Replace the tall, uneven 3-column priority layout with grouped vertical sections or a stable responsive grid. Highlight priorities (High, Medium, Low) with consistent badges.

### 8. QA Review Tab
*   **Change:** Refine the review gate layout. Ensure status counters are clean. Use clear institutional copy rather than simulated AI scanning notes.

### 9. Brief Tab
*   **Change:** Style the brief like a premium white paper canvas with generous margins, a clean header metadata bar, and the raw markdown code block collapsed within a details folder.

### 10. Traceability Drawer & TraceChain
*   **P0 Change:** Elevate TraceChain breadcrumbs in the drawer using clear, clickable nodes showing the full flow from source to recommendation. Highlight the current node in bold teal.

---

## 5. What Will and Will Not Change
*   **WILL CHANGE:** Layout containers, cards, tab bars, colors, typography styles, button hierarchies, and responsive wrappers.
*   **WILL NOT CHANGE:** App authentication, backend processing, database calls, external AI integrations, or core types schema definitions.

---

## 6. Risks
*   **Type Regression:** Large components require precise component-level edits. Ensure TypeScript builds successfully after changes.
*   **Responsive Breakdowns:** Verify layouts on laptop and tablet sizes.
